### 📄 [DocParse](https://github.com/Dhartharis/docparse)

A document-processing platform combining a **.NET backend with RAG and semantic search**.

Documents are processed and stored using MongoDB, converted into embeddings, indexed using PostgreSQL + pgvector, and retrieved as context for natural-language queries.

**Stack**

`.NET 8` · `Clean Architecture` · `MongoDB Atlas` · `PostgreSQL` · `pgvector` · `OpenAI` · `RAG` · `Docker` · `GitHub Actions`
